# Repo Auditor

Repo Auditor is a comprehensive tool suite designed to recursively scan local Git repositories, extract their software architecture, map interdependencies, and run local security scans. It generates interactive architecture maps and security reports in Markdown, utilizing Mermaid.js for diagrams.

The project is split into two main components:
1.  **`repo-auditor` (Go CLI)**: The high-speed backend engine that performs the heavy lifting.
2.  **`repo-auditor-extension` (VS Code Extension)**: The graphical frontend providing a seamless developer experience directly inside VS Code.

---

## Project Structure

```text
.
├── repo-auditor/                   # The Go CLI application
│   ├── cmd/auditor/                # Entrypoint for the CLI (main.go)
│   ├── pkg/analyzer/               # Logic for scanning files, detecting technologies (Go, Node, Spring, Quarkus) and mapping dependencies
│   ├── pkg/renderer/               # Markdown generation with Mermaid.js integration
│   ├── pkg/security/               # Security scanning logic integrating Trivy, Hadolint, and Gitleaks
│   ├── go.mod                      # Go dependencies
│   └── architecture_map.md         # Example output generated by the CLI
│
└── repo-auditor-extension/         # The TypeScript VS Code Extension
    ├── src/                        # Extension source code
    │   ├── extension.ts            # Extension entrypoint, command registration, and binary execution logic
    │   └── panels/                 # UI panels
    │       └── ArchitectureWebview.ts # Webview rendering Mermaid.js diagrams interactively
    ├── package.json                # Extension manifests and configurations
    └── tsconfig.json               # TypeScript compiler configurations
```

## Usage

### 1. The `repo-auditor` CLI (Go)

The CLI is the core engine. It uses a concurrent worker pool to scan your folders for `.git` repositories and analyzes their contents.

#### Prerequisites
*   Go 1.21+ installed.
*   (Optional but recommended for full security reports):
    *   [Trivy](https://aquasecurity.github.io/trivy/) (Available in PATH)
    *   [Hadolint](https://github.com/hadolint/hadolint) (Available in PATH)

#### Building and Running

1. Navigate to the CLI directory:
   ```bash
   cd repo-auditor
   ```
2. Build the application:
   ```bash
   go build -o repo-auditor ./cmd/auditor
   ```
3. Run the scan on a target directory:
   ```bash
   ./repo-auditor --path /path/to/your/projects --concurrency 8
   ```

The output will be an `architecture_map.md` file saved at the root of the scanned path. It will contain the Topology diagram, the Data Flow diagram, and a "Rapport de Sécurité Flash".

---

### 2. The `repo-auditor-extension` (VS Code Extension)

The extension wraps the Go CLI to provide a one-click visual experience inside VS Code.

#### Prerequisites
*   Node.js (18.x+) and npm installed.
*   VS Code (1.80.0+) installed.
*   **Crucial**: The `repo-auditor` Go binary must be compiled and available in your system's PATH, or you must configure its path in the VS Code settings under `repoAuditor.binaryPath`.

#### Compiling the Extension

1. Navigate to the extension directory:
   ```bash
   cd repo-auditor-extension
   ```
2. Install the Node modules:
   ```bash
   npm install
   ```
3. Compile the TypeScript code:
   ```bash
   npm run compile
   ```

#### Running and Debugging in VS Code

1. Open the `repo-auditor-extension` folder in VS Code.
2. Press `F5` to start debugging. This opens an "Extension Development Host" window.
3. In the new window, open the Command Palette (`Ctrl+Shift+P` or `Cmd+Shift+P`) and type:
   **`Audit Repository`**
4. Select the folder containing the projects you want to scan.
5. The extension will run the Go binary in the background, read the output, and display an interactive Webview with your rendered Mermaid diagrams and security reports. You can refresh the view or copy the diagrams easily.
